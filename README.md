这一点对决策有实际影响。注册地和主体不清，意味着真出纠纷时，你能用的渠道主要是支付端，而不是某个可查的境内主体。

## 带宽先换算成 MB/s，再决定买不买

“不限流量”四个字在这张表里出现了 8 次，但配上 10Mbps 到 30Mbps 的带宽，实际体验和很多人的预期差得远。

10Mbps 除以 8，峰值下载约 1.25 MB/s。下载一个 1GB 的文件，理论上要十三分钟出头。20Mbps 是 2.5 MB/s，30Mbps 是 3.75 MB/s，50Mbps 是 6.25 MB/s。只有 LA-VP04-L 那款 1Gbps 能跑到约 125 MB/s，但它是 1核1G 配 500G 双向流量，$19.9/月。

这决定了 LightLayer 适合什么。挂博客、跑 Telegram 机器人、做 API 中转、放个小体积的静态站，1.25 MB/s 完全够用，而且不限流量意味着你不用盯着月度额度。但如果你要传大文件、做下载站、跑视频中转、当 CDN 回源，10–50Mbps 会成为硬的瓶颈，超了也不会停机，就是慢，慢到你会想换。

有一个第三方测评细节值得参考：针对菲律宾马尼拉机房的 traceroute 记录显示，到广州联通的路径会经香港、新加坡、洛杉矶绕行，延迟接近 300ms。低价机房的“Global”线路通常是国际互联优先，回国优化并不在其中。

## 常见问题

**国人小商家一定跑路吗？**

不一定。经营年限是目前最可观察的替代指标，能从一个行业周期活到下一个、还在持续扩产品线的商家，已经过了一轮筛选。真正需要警惕的是组合特征：新成立、超低价年付、只在论坛和电报群获客。有过一个具体案例，某商家在五一办特价年付活动，5 月 10 日被爆机器全部离线、网站关闭、电报群解散、老板电报销号，最后是用户投诉到支付端，商家才现身承诺退款。

**月付比年付贵多少？**

以 LightLayer 香港同配置两款算：HK-VP02 月付 $5，一年 $60；HK-VP02-A 年付 $24.99。年付便宜约 58%。但后者是促销款，不定期补货，缺货时这个差价拿不到。

**没有退款还能买吗？**

能，前提是把第一单的金额控制在你不在乎的范围内。LightLayer 只认商家责任退款，第一单选 $4–5 的月付最小配置，等于用一个月租金买验证期。确认线路和稳定性之后再考虑年付。

**支付宝付款出问题找谁？**

支付渠道本身是维权杠杆。前面那个跑路案例里，用户正是投诉到支付端才迫使商家出面。所以尽量走有争议处理机制的渠道，保留订单号和付款记录。LightLayer 的支付方式在第三方目录里记录为 PayPal 和信用卡，另有条目列了支付宝，实际可用渠道以结算页显示为准。

**促销款和常规款配置一样，为什么价格差这么多？**

HK-VP02-A 的 $24.99/年本质上是拉新款，用年付锁定用户、换取现金流，配置不缩水。风险在于促销款库存不定，且同样不适用退款。
